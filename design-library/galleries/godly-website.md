# godly.website (сейчас открывается как Recent, recent.design)

- Ссылка: https://godly.website, дата разбора 29.09.2026, категория: галереи.
- Редирект: godly.website перенаправляет на https://recent.design/?ref=godly (заголовок вкладки «Recent — Design Inspiration»). Значит, это уже другая галерея. Собственного контента Godly мы не видели.

## Что снято на живой странице (computed styles)
- Фон страницы rgb(255,255,255), текст rgb(11,11,11), заголовки и ссылки oklch(0.15 0 0), приглушённый текст oklch(0 0 0 / 0.267).
- Шрифт: Inter (запасной ui-sans-serif, system-ui). Размеры мелкие: основной 13px, «h1» («Design») 16px, вес 500. Кириллицу в этом интерфейсе не проверяли.
- Вёрстка: боковое меню слева (Design, Websites, UI/UX, Branding, Product, Typography, Motion, Illustration, 3D, Editorial, Print, Packaging), в центре масонри-сетка карточек (62 картинки, 16 видео), справа колонка вакансий. Фильтры-«чипы» по категориям.
- GSAP, three.js, Lottie, Lenis не найдены; canvas 0. Единственный внешний скрипт: аналитика cdn.visitors.now.

## Чем силён
- Интерфейс-рамка: белый, тихий, почти без декора, чтобы работы (карточки) были единственным цветом. Пример того, как подавать контент без шума.
- Плотная сетка разной высоты с видео-превью, ритм задаёт сам контент.
- Категории «Typography», «Motion», «3D», «Branding» удобны как навигация по приёмам.

## Что брать / не брать
- Брать: как источник свежих референсов по категориям (фильтры Web, Typography, Motion, 3D).
- Не брать: интерфейс как образец для «Вау» (он намеренно нейтральный).

## Не проверено
- Работает ли фильтр по нишам, лицензии шрифта Inter (обычно OFL, в этом разборе не проверялась).
