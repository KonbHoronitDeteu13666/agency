# UX patterns library

Notes on how strong sites and bots solve usability, by niche or topic. Filled by `reference-scout` and `ux-designer`, read first by `ux-designer`.

## Files
- `standards.md`: current usability and accessibility standards checked on the web: WCAG version in force, touch target guidance, Core Web Vitals thresholds, search engine mobile requirements, form guidance. Always with date and source URL.
- `<niche-or-topic>.md`: patterns for one niche (for example `cafe.md`, `barbershop.md`, `auto-service.md`) or topic (`booking-form.md`, `telegram-bot-menu.md`).

## Note format (up to 40 lines)
Date checked; sources (URLs, at least 3 for a niche note); what was observed on live pages, with real numbers (number of form fields, taps to the main action, where the main action sits, menu depth, section order); patterns that repeat across sources; what to take and what not; not verified. Observed facts only, never invented.

## Freshness
A note older than 90 days is stale: `ux-designer` re-verifies it before relying on it and updates the date.
