# Making Software (Dan Hollick)

- Ссылка: https://makingsoftware.com (редирект на www). Дата разбора 29.09.2026. Категория: иллюстрации, чертёжная изометрия.

## Снято на живой странице
- Фон rgb(251,251,251), текст rgb(0,0,0). Акцент в SVG rgb(19,66,255) (частые синие: oklch 0.5058 0.2886 264.84, display-p3 0.073 0.259 1), бледно-голубой заливки.
- Шрифты в коде: arizona (запасной EB Garamond), Departure Mono для заголовка 60 px.
- Next.js. canvas 0, video 0, SVG 45. GSAP, three.js, Lottie не найдены.

## Чем силён
- Изометрические разборные схемы тонкой линией, подписи-выноски моно-шрифтом, один яркий синий у главных деталей. Без фото и градиентов.

## Брать / не брать
- Брать: технику линии и единый акцент для серии сценок. Не брать: авторский рисунок и шрифты.

## Не проверено
- Анимация при прокрутке, телефон, лицензии шрифтов, кириллица.
