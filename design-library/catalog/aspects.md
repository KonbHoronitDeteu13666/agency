# Аспекты: что взять из референсов, даже «забракованных»

Принцип владельца (14.10.2026): референс не бракуется целиком. У одного понравились цвета, у другого раскладка, у третьего кнопка, шрифт, тень. Вердикт «НЕ БРАТЬ», «СТОП» или «ТОЛЬКО ВАУ» относится к конкретному приёму (неон, стрелочный слайдер, клетчатый фон), а палитра, раскладка блоков, форма кнопки, пара шрифтов, пропорции и отступы берутся отдельно. Запреты декора из `CLAUDE.md` остаются для самих приёмов, не для цветов и раскладки.

Как читать: «Режим» значит, где аспект можно применять. Стандарт = можно в обоих режимах, Вау = только в режиме «Вау». Файлы: коды частей (A, B, C, D, V) в `design-library/catalog/`, картинки в `design-library/sources/` по номерам из этих частей. Картинки при составлении таблицы заново не открывались: разбор опирается на записи частей, это ограничение.
