## 3. Типографика

Пары (заголовок + текст) прочитаны с картинок. Кириллицу и лицензии написал по памяти: перед использованием проверять в Google Fonts, иначе «лицензия не проверена». Без кириллицы русским сайтам не предлагать.

- Playfair Display + Inter; Cormorant Garamond + Manrope (8a2af248). Кириллица есть у всех четырёх. ВЗЯТЬ. Bodoni Moda + Montserrat: у Bodoni Moda, вероятно, нет кириллицы, проверить.
- Lora + Montserrat; Forum + DM Sans; Marcellus + Nunito Sans; Abril Fatface + Open Sans; Cinzel + Raleway (74d4ccdf, d9ecdb7f, 8df04dbf). Кириллица есть у Lora, Montserrat, Forum, Open Sans, Raleway, Nunito Sans; у Abril Fatface, Cinzel, Marcellus, DM Sans, вероятно нет. ВЗЯТЬ Lora + Montserrat, Forum + Open Sans.
- EB Garamond + Inter; Source Sans 3 (5eeb7e64, f80a3dea): ВЗЯТЬ, кириллица есть.
- Prata, Cormorant, Playfair + Manrope (be2b3c9f): с кириллицей. Poppins без кириллицы, вероятно. Подача на лиловом неоне ТОЛЬКО ВАУ.
- Canela, Avenir, Futura (61a7e921, f80a3dea, 8df04dbf): платные, НЕ БРАТЬ. Fraunces, Italiana, Tenor Sans, Gloock: кириллица под вопросом.
- Рукописные Great Vibes, Parisienne, Sacramento, Allura (772b7127, f80a3dea, 5eeb7e64): без кириллицы, НЕ БРАТЬ для русских сайтов.
- Принцип подборок: выразительный засечный заголовок из 2 слов, одно слово курсивом или в цвете акцента, плюс спокойный гротеск текста; малые подписи капсом с разрядкой над заголовком. ВЗЯТЬ умеренно.
- Золотой градиент на буквах заголовка (772b7127): НЕ БРАТЬ. Бумага, сургуч, засушенные веточки, обрывки писем, орнаментальные дуги (f80a3dea, 8a2af248, 74d4ccdf): НЕ БРАТЬ, декор формата соцсетей.
