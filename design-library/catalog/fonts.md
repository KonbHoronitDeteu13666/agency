# Шрифты: кириллица и лицензия (проверено 14.10.2026)

Как проверено: открыты публичные файлы описания шрифтов официального репозитория Google Fonts (github.com/google/fonts, файл METADATA.pb каждого шрифта: поле license и список subsets). Страницы fonts.google.com/specimen/ рисуются скриптом и текстом не читаются, поэтому смотрели репозиторий, из которого их строит сам Google. Кириллица = есть набор cyrillic. Лицензия OFL = свободная, коммерческое использование разрешено, встраивание на сайт разрешено. Платных среди проверенного нет. Ссылка у всех вида fonts.google.com/specimen/<Имя>.

## Аналоги для шрифтов без названия (все: кириллица да, OFL, Google Fonts)

Широкий (extended) гротеск для слогана (part-V, v4, v10), только Вау:
- Unbounded: самый близкий, широкий, крупный.
- Montserrat Alternates: геометрия, шире обычного Montserrat.
- Exo 2: техно-ширина, в крупном размере.

Округлый «пухлый» display для заголовка (part-V, v8), только Вау:
- Rubik (жирные начертания): скруглённые углы, читаем.
- Nunito (900): мягкий и округлый.
- Dela Gothic One: плотный тяжёлый (кириллица есть, расширенной нет). Fredoka кириллицы не имеет, не брать.

Сжатый жирный гротеск капсом (v1, v9) и блочный квадратный (part-V, v-еда): Russo One (кириллица да), Onest и Golos Text жирные (кириллица да, подходят и для Стандарта как основной текст).

Моноширинный (v2): JetBrains Mono, кириллица да, OFL; для сайта малого бизнеса не брать.

## Не проверено по сети

- Fontshare (Satoshi, Cabinet Grotesk и др.): страницы строятся скриптом и текст не читается, кириллица и лицензия не проверены. Fontshare в основном латиница, русским сайтам не предлагать без отдельной проверки.
- Wix Madefor Display: адрес в репозитории не нашёлся, не проверено.
- Платность Canela, Avenir, Futura: по общему знанию, не по сети.
- Вид начертаний (какие веса есть у каждого шрифта) не проверялся.
