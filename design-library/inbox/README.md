# Входящие: сюда кидай всё, что понравилось

Скриншоты, фото, кадры из видео. Без сортировки и без подписей: описание уже на самом скриншоте. Просто кидай в эту папку.

## Что здесь бывает
- Визуальные приёмы и интерфейсы.
- Правила и принципы (тени, размеры текста, отступы, контраст, «так хорошо / так плохо»).
- Сочетания цветов.

## Кто что делает
Классификацию делает главный агент вместе с `reference-scout`. Владелец ничего не сортирует. По запросу «разбери входящие»:
1. Читаем каждый скриншот, включая текст на нём.
2. Раскладываем по разделам каталога `design-library/`: приёмы, правила и запреты (хорошо/плохо, с цифрами), палитры (сочетания цветов с кодами), типографика, тени и отступы, анимации.
3. Решаем, что брать в работу, а что отложить или отбросить. Спорные и противоречащие нашим правилам случаи показываем владельцу списком.
4. Обработанные файлы переносим из `inbox/` в `design-library/` в нужный раздел, чтобы входящие не копились.

## Видео
Агенты видео не смотрят. Нужны 2–4 скриншота ключевых моментов. Если описание есть на кадре, отдельный текст не нужен.

## Правила
- Берём приём и идею, чужой макет один в один не копируем.
- Если правило противоречит слову владельца или `departments/design-taste.md`, побеждает слово владельца (`departments/skill-precedence.md`).
- Папка не коммитится в git (тяжёлая).
