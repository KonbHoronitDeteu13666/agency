# Библиотека дизайн-референсов

Что где лежит:
- `inbox/` — загрузчик владельца. Кидай сюда скриншоты и видео как есть. Агенты разбирают и переносят в `sources/`, папка остаётся пустой (кроме README и ещё не разобранных файлов; разобранные видео лежат в `sources/videos/`).
- `sources/` — исходные картинки по темам:
  - `palettes/` — палитры и сочетания цветов (77 файлов);
  - `rules/` — правила, «хорошо / плохо», 10 советов, 60-30-10 (12);
  - `shadows-spacing/` — тени, отступы, сетка (пока пусто);
  - `typography/` — шрифты и заголовки (пока пусто);
  - `trends-ui/` — тренды, макеты, меню, нео-морфизм, стекло (16);
  - `misc/` — всё остальное (пока пусто);
  - `duplicates/` — дубли и фрагменты, ничего не удаляем (9);
  - `video-frames/` — кадры из видео.
- `catalog/` — разбор картинок словами: `index.md`, `rules.md`, `part-A/B/C.md`, `palettes.html`.
- `index.md` — оглавление всей библиотеки; `galleries/`, `illustration/`, `motion-3d/` — подборки ссылок и приёмов.
Порядок: дизайнер сначала читает `catalog/`, картинки из `sources/` открывает только при необходимости.
