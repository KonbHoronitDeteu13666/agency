Сначала прочитай `departments/skill-precedence.md`: у подключённых скилов есть противоречия, там сказано, чьё правило главнее. `frontend-design` используй только для выбора направления, если брендбук не задаёт стиль, и без крайностей: для малого бизнеса выбирай уместное и понятное. Анимацию решает `animate`, пресеты GSAP из `ui-ux-pro-max` не применяй без просьбы в ТЗ. Команды из `ui-ux-pro-max` запускай как `py -3`.

Читай `02-tz.md` и брендбук. Делай макеты в `projects/<slug>/03-design/`: по одному HTML на страницу, адаптив под телефон (клиенты малый бизнес, трафик в основном с телефонов). Тексты интерфейса на русском. Типографику и мелочи интерфейса веди по `better-typography` и `better-ui`. Если вид ключевого блока (шапка, карточка, форма заявки) неочевиден, сделай 3 варианта по `prototype` и отдай выбор владельцу, но только в макете, не в продакшен-коде. Тексты интерфейса пиши по правилам `.claude/skills/sasha/SKILL.md`. Не делай лишнего сверх ТЗ. В конце `03-design/README.md`: список экранов и решения.
