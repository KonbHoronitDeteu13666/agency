Сначала прочитай `departments/skill-precedence.md` (у скилов есть противоречия, там сказано, чьё правило главнее) и `departments/design-taste.md`; `departments/wow-effects.md` читай только в режиме «Вау». Скилы целиком не заливай в контекст, читай по необходимости: `prototype` только когда нужны 3 варианта блока; `animate` только если есть интерфейсные движения; `ui-ux-pro-max` файлом не читай, а запускай поиск по запросу: `py -3 C:\Users\HP\.claude\skills\ui-ux-pro-max\scripts\search.py "<запрос>" --domain typography`. Выполни процесс из `design-taste.md`, раздел 2: библиотека `design-library/`, 3–5 живых референсов, идея сайта одной фразой, отличие от «нейронного» шаблона, самопроверка глазами. Режим («Вау» или «Стандарт») задаёт владелец; в режиме «Вау» делай смело: сильная идея, характерные шрифты, необычная композиция, выразительное движение, 3D, где уместно, с условиями качества из `wow-effects.md`. Интерфейсные движения проверяет `animate`. Пресеты GSAP из `ui-ux-pro-max` без причины не применяй. Для самопроверки поднимай локальный сервер `py -3 -m http.server` в папке макета и смотри страницу в браузере на ширине 360 и 1280. Команды из `ui-ux-pro-max` запускай как `py -3`.

Читай `02-tz.md` и брендбук. Делай макеты в `projects/<slug>/03-design/`: по одному HTML на страницу, адаптив под телефон (клиенты малый бизнес, трафик в основном с телефонов). Тексты интерфейса на русском. Скриншоты в браузере снимай масштабом 0.5 и только когда нужно увидеть вид, данные страницы бери текстом. Если вид ключевого блока (шапка, карточка, форма заявки) неочевиден, сделай 3 варианта по `prototype` и отдай выбор владельцу, но только в макете, не в продакшен-коде. Тексты интерфейса пиши по правилам `.claude/skills/sasha/SKILL.md`. Не делай лишнего сверх ТЗ. Макеты делаются так, чтобы владелец их видел: страницы HTML открываются двойным щелчком и не требуют сервера. Добавь `03-design/index.html`: список всех экранов с крупными превью (iframe) и ссылкой на каждый, для телефона и ноутбука. В конце `03-design/README.md`: список экранов и решения.
