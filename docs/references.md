# Подборка сайтов-источников

Источник: https://designich.notion.site/3c96d6c8727d8052a13de65842fcef05 («Подборка сайтов для вайбкода», прочитана 29.09.2026). Это не галереи готовых дизайнов, а библиотеки эффектов, анимаций, компонентов, шрифты, логотипы и дашборды. Сами сайты я пока не открывал и лицензии не проверял, это делает разведчик по мере надобности.

| Категория | Сайты | Кто использует | Ограничение |
|---|---|---|---|
| Эффекты | reactbits.dev, kinetics.colorion.co, 21st.dev, cursify.ui-layouts.com, fancycomponents.dev | `ui-designer` как источник идей, если ТЗ просит эффектный сайт | эффекты почти всегда на React; для статичного сайта S не подходят; движение решает `animate` |
| Анимации | gsap.com/showcase, motion.dev, unicorn.studio, animejs.com, number-flow.barvian.me | `web-dev` по решению `animate` | `gsap.com/showcase` только для вдохновения; библиотеки подключаем только если без них не обойтись |
| Компоненты | spell.sh, magicui.design, interior.dev, ui.shadcn.com, astryx.atmeta.com | `web-dev` в проектах на React (M и L) | стек задаёт ТЗ; для статичных сайтов не нужны |
| Шрифты | bestfreefonts.com, fontshare.com | `brand-designer` | обязательны кириллица и проверка лицензии на коммерческое использование; у Fontshare многие шрифты только латиница |
| Логотипы | logosystem.co | `brand-designer` как вдохновение для направлений логотипа | не копировать; логотип предлагает владельцу как направление |
| Дашборды | bklit.com, tremor.so | `web-dev` в проектах с панелями данных (M и L) | только если ТЗ включает дашборд |
| Коллекция | designengineer.tools | `reference-scout` для поиска других источников | |

## Правила
- Берём идеи и приёмы, не копируем чужой код, тексты и картинки. Использование компонента только по его лицензии, лицензию записываем в заметки проекта.
- Вход в аккаунты и регистрация на этих сайтах запрещены без «да» владельца в чате. Если нужна регистрация, агент возвращает вопрос.
- Приоритет этих источников ниже, чем у ТЗ, брендбука и макетов, и подчинён таблице `departments/skill-precedence.md`.
