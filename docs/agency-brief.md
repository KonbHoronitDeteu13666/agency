# Виртуальное IT-агентство из агентов: контекст и план

Файл для передачи в Claude Code. Собран из диалога от 29.09.2026.

## 1. Что делаем

Небольшое виртуальное IT-агентство для себя. Агенты берут на себя отделы полного цикла: маркетинг, поиск клиентов, подготовка продаж, производство продукта, тестирование, закрытие проекта. У каждого отдела предполагается оркестрирующий агент и подчинённые ему субагенты.

Текущая задача: спроектировать архитектуру агентства (отделы, агенты, память, запуск).

## 2. Вводные (ответы владельца)

**Продукт и клиенты**
- Продукт: всё сразу (сайты, приложения, боты, автоматизации, ИИ-агенты) в разумных пределах сложности. Владелец не программист, из инструментов только Claude Code.
- Клиент: малый бизнес.
- Чек: от 10 000 руб., срок проекта 1-3 дня.

**Продажи и сделки**
- Поиск клиентов: холодный outreach, контент, поиск активных бизнесов в соцсетях без своего сайта.
- Общение с клиентом: только лично владелец. Агенты участвуют только в поиске потенциальных клиентов и подготовке материалов.
- «Закрытие сделки» = планировщик дедлайнов и подобное. Владелец работает как частное лицо, без ИП.

**Производство**
- Стек: только Claude Code.
- Тестирование: код, дизайн, тексты, соответствие ТЗ клиента.
- Нужны все отделы: дизайн, копирайтинг, поддержка после сдачи.

**Управление**
- Владелец выступает прослойкой между агентами и заказчиком: задаёт клиенту вопросы, передаёт агентам материалы и референсы, согласует брендбуки и результаты.
- Только владелец: цены, отправка сообщений клиенту, публикации, оплата, всё общение с клиентом.
- Общая память между отделами (CRM, история клиентов, шаблоны): да.

**Ресурсы**
- Время: до 12 часов в день на управление.
- Бюджет: около 10 000 руб./мес. на инструменты и API, без учёта подписки Claude.
- Где работает система: не определено, предложены варианты (см. п. 5).

## 3. Предлагаемая архитектура

Над всем стоит главный агент, единственная точка входа для владельца.

1. **Лидогенерация**: поиск бизнесов без сайта в соцсетях и картах, проверка (активность, нет сайта), карточка лида с контактами и гипотезой оффера.
2. **Маркетинг и контент**: контент-план, копирайтер, визуал, кейсы и портфолио.
3. **Подготовка продаж**: черновики первых сообщений, скрипты, вопросы для брифа, КП и смета, разбор возражений. Отправляет только владелец.
4. **Аналитика и ТЗ**: превращает бриф и материалы клиента в ТЗ.
5. **Дизайн и брендинг**: брендбук, референсы, макеты.
6. **Разработка**: сайты, боты, автоматизации, интеграции.
7. **Тестирование (QA)**: код, дизайн, тексты, соответствие ТЗ.
8. **Проектный офис**: планировщик дедлайнов, статусы, шаблоны документов, закрытие проекта.
9. **Поддержка после сдачи**: правки, инструкции клиенту, типовые ответы (черновики для владельца).

**Общая память** (папка проекта): `leads/`, `clients/`, `projects/`, `templates/`, `brandbooks/` и файл `CLAUDE.md` с правилами. Это CRM без отдельных сервисов.

**Правила автономности:** агенты готовят, владелец утверждает. Отправка клиентам, цены, публикации и оплата остаются за владельцем.

**Ограничение (проверить в документации Claude Code перед реализацией):** насколько известно, субагент не может вызывать других субагентов. Поэтому «оркестратор отдела» лучше делать регламентом отдела (файл с порядком работы), который выполняет главный агент, вызывая субагентов отдела напрямую.

## 5. Варианты запуска

- **A. Claude Code локально.** Бесплатно, проще всего, всё под контролем. Минус: работает, только пока включён компьютер.
- **B. Claude Code на VPS.** Около 500-1500 руб./мес. Работает круглосуточно. Минус: нужна настройка сервера.
- **C. Облачные сессии Claude по расписанию.** Без своего сервера, подходит для регулярных задач вроде поиска лидов. Минус: меньше контроля над окружением.
- **D. Самописная система на API или n8n.** Дорого и сложно для не-программиста, не рекомендуется.

**Рекомендация:** начать с A, проверить отделы, инструкции и файловую память. Затем вынести лидогенерацию в C или B. Укладывается в 10 000 руб./мес.

## 8. Что сделать дальше (задача для Claude Code)

1. Прочитать `C:\Users\HP\.claude\skills` и `C:\Users\HP\.claude\plugins`, составить реестр: имя, назначение, отдел, что доработать.
2. Проверить по ссылкам найденные UI-скиллы (содержимое, лицензия, безопасность) и решить, какие ставить.
3. Проверить в документации Claude Code ограничение по вложенным субагентам и принять решение по оркестраторам (регламент отдела или агент).
4. Создать структуру проекта: `CLAUDE.md`, папки памяти, папка агентов и регламентов отделов.
5. Расписать субагентов и инструкции отделов. Порядок: аналитика и ТЗ, дизайн, разработка, QA, затем лидогенерация, маркетинг, подготовка продаж, проектный офис, поддержка.

Ограничения для всей работы: общение с клиентом, цены, публикации и оплата только у владельца; бюджет около 10 000 руб./мес.; владелец не программист, поэтому объяснять просто и не усложнять.
