## UI-скиллы из Notion (установлены 29.09.2026 в `.claude/skills/`)
Файлы всех скиллов просмотрены целиком, шеллом и сетью они не пользуются. Единственные скрипты у sasha: два python-файла на стандартной библиотеке, читают только указанный файл, в сеть не ходят, второй подгружает соседний. Вредоносного не найдено. Проверялся клон репозиториев на 29.09.2026, при обновлении проверять заново.

| Скилл | Лицензия | Где подключён | Как используется |
|---|---|---|---|
| better-ui | MIT | ui-designer, web-dev, qa-design | правила деталей интерфейса; у QA как чек-лист |
| better-typography | MIT | ui-designer, web-dev, qa-design | шрифты, интервалы, переносы; у QA как чек-лист |
| animate | MIT | web-dev | анимация только там, где она есть в ТЗ и макете |
| pick-ui-library | MIT | web-dev | подбор библиотеки, только если без неё не обойтись; для статичного сайта не нужна |
| prototype | MIT | ui-designer | 3 варианта неочевидного блока на выбор владельцу, только в макете |
| sasha | в репозитории deslop файла лицензии нет | copywriter, qa-copy, ui-designer | русские тексты интерфейса, сайтов и инструкций; линтер `ui_text_lint.py` у qa-copy |

Не установлено: impeccable (скачивает исполняемый файл и ставит хук на каждую правку), каталог UI Skills (это каталог, не скилл).

Python: `python`/`python3` в PATH указывают на заглушку Windows, настоящий Python 3.10 установлен, запускается как `py -3`. В агентах прописано `py -3`. Системные настройки не менялись.
